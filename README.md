# Strava 工具箱（Tampermonkey 用户脚本）

一个运行在浏览器里的 Strava 增强脚本：自动点赞、一键 @ 回复评论、悬浮球面板、个人主页训练统计、隐藏付费推广。

- 当前版本：**v1.9.1**
- 适用站点：`www.strava.com`（信息流 / 活动页 / 俱乐部 / 个人主页）
- 运行方式：Tampermonkey（油猴）用户脚本，全部逻辑在本地浏览器执行，不上传任何数据

---

## 功能

### 1. 自动点赞
- 按**活动日期**选择范围：今天 / 近 3 天 / 近 7 天 / 近 10 天 / 不限 / 自定义日期
- 按**对象**选择：全部点赞、只给白名单、跳过黑名单（名单可写名字或运动员 ID）
- 支持信息流、俱乐部动态、他人主页里的活动卡片
- 点赞间隔 2–4 秒随机，模拟人工操作；失败会在日志里提示原因（如 401 / 429 限流）
- 可随时暂停/继续；「演练模式」只扫描不点赞，先确认范围是否合适
- 已赞过的活动会记录到本地，不会重复处理

### 2. 一键 @ 回复评论
在活动页打开评论弹层后，每条评论旁会出现回复按钮，点一下自动在评论框填入 `@对方名字`，接着输入内容即可。

### 3. 环形悬浮球 + 四页签面板
页面右侧的圆形悬浮球：**点击圆球回到页面顶部**；圆球周围的环形扇区是四个页签入口，点对应扇区打开面板：

| 页签 | 内容 |
| --- | --- |
| 点赞 | 点赞范围、预览模式、包含俱乐部动态、开始/继续扫描、实时日志；子页签「点赞统计」查看最近一次点赞 |
| 名单 | 选择点赞对象（全部 / 白名单 / 黑名单）、识别关注列表、维护白黑名单 |
| 分析 | 个人主页的今日训练与周期统计 |
| 设置 | 点赞间隔、付费推广隐藏开关、清空点赞记录 |

悬浮球可拖动，松手自动吸附到左右边缘；再次点击已打开的扇区会收起面板。

### 4. 个人主页训练统计（分析页签）
- **只在个人主页（`/athletes/{id}`）生效**，其他页面会提示先打开某人的主页
- 「今日训练」：当前主页这个人今天的活动条数与总里程
- 「训练统计」：近 7 天 / 近 30 天 / 不限，统计次数、总里程、平均每次里程
- 数据来源：
  - 自己的主页 —— 读取训练日志，覆盖近 12 周，数据准确
  - 别人的主页 —— 只能读取页面已加载的活动卡片（Strava 不公开他人的完整训练日志），通常是最近几条

### 5. 隐藏付费推广
可分别开关：页头推广、信息流推广、模块位推广、页脚推广、软文式推广。

## 新手安装（3 步）

### 第 1 步：安装 Tampermonkey
先安装浏览器扩展「Tampermonkey（油猴）」：

- Chrome / Edge：打开应用商店搜索 **Tampermonkey**，或访问 <https://www.tampermonkey.net/>
- Firefox：<https://addons.mozilla.org/firefox/addon/tampermonkey/>
- Safari：App Store 安装 **Userscripts**（或 Tampermonkey）

安装完成后，浏览器右上角会出现 Tampermonkey 图标。

### 第 2 步：安装脚本
点击下面的链接，Tampermonkey 会自动弹出安装页面，点「安装」即可：

**👉 [安装 / 更新 Strava 工具箱](https://raw.githubusercontent.com/ShenDoyle/js_stravapilot/main/strava-auto-kudos.user.js)**

> 如果打开后看到的是源码文本，请确认 Tampermonkey 已启用，或复制全文，在 Tampermonkey 管理面板中新建脚本粘贴保存。

### 第 3 步：打开 Strava 验证
1. 登录 <https://www.strava.com/>
2. 打开信息流 <https://www.strava.com/dashboard>
3. 页面右侧出现圆形悬浮球，说明安装成功；点圆球周围环上的扇区即可打开「点赞 / 名单 / 分析 / 设置」面板

## 使用建议

1. 先打开「点赞」页签，勾选 **预览模式（只标记不点赞）**，把「点赞范围」设为近 7 天，点「开始自动点赞」，看日志里命中的活动是否符合预期
2. 确认无误后取消预览模式，再正式点赞
3. 想只给熟人点赞：在「名单」页点「识别关注列表」，把需要的人加入白名单，「点赞对象」选「只给白名单点赞」
4. 查看训练数据：进入任意人的个人主页，从悬浮球环上打开「分析」

## 常见问题

**Q：悬浮球没有出现？**
- 确认 Tampermonkey 图标上显示脚本数量 ≥ 1，且脚本处于启用状态
- 确认当前地址是 `https://www.strava.com/...`（不是手机 App、不是第三方嵌入页）
- 刷新页面；若仍无效，在 Tampermonkey 面板里检查是否有报错

**Q：点赞没有反应 / 提示失败？**
- 需要保持 Strava 登录状态；脚本使用页面内的 CSRF token 调接口
- 自己的活动、已经点过赞的活动会被跳过，属于正常现象
- Strava 偶尔会限流，建议把间隔调大、范围调小，稍后再试

**Q：训练统计数字偏少？**
- 别人的主页只渲染最近几条活动，脚本只能读到页面上已有的内容，这是 Strava 的限制
- 自己的主页会读取训练日志（近 12 周），数据更完整

**Q：训练统计一直是 0 / 提示打开主页？**
- 该统计只在个人主页 `/athletes/{id}` 生效，首页和信息流不统计

**Q：配置存在哪里？**
- 全部存在浏览器本地 `localStorage`（键名以 `sak:` 开头），不会上传；「设置」页可清空点赞记录，清理浏览器数据会重置全部配置

**Q：如何更新？**
- Tampermonkey 会按脚本版本号自动检查更新；也可以重新点上面的安装链接覆盖安装

**Q：会被封号吗？**
- 脚本只是代替你点击页面按钮，并加入随机间隔；但仍建议控制频率、避免短时间大量点赞，风险自负
